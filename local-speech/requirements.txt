# On-prem STT + TTS + LLM gateway for the triage backend.
#
# Platform-aware on purpose: the CUDA pins below are Windows/Linux only. On
# macOS there is no CUDA at all, and installing this file without the markers
# fails outright — no +cu124 torch and no nvidia-* wheels exist for Darwin.
fastapi
uvicorn[standard]
python-multipart
httpx
python-dotenv

# ── STT ────────────────────────────────────────────────────────────────────
# faster-whisper runs on ctranslate2, NOT torch, so on a CUDA box it needs its
# own CUDA libraries even when torch is present. Without them get_stt() falls
# back to CPU int8 and only says so in one log line.
# ctranslate2 4.x wants cuDNN 9 against CUDA 12.
faster-whisper
nvidia-cublas-cu12    ; sys_platform != "darwin"
nvidia-cudnn-cu12>=9  ; sys_platform != "darwin"

# ── Instrumentation for /metrics ───────────────────────────────────────────
# Both were imported but never declared, so the Probe's sampling thread died
# with ModuleNotFoundError on every single request — visible only as a
# traceback and null gpu/cpu/vram fields. nvidia-ml-py also replaces shelling
# out to nvidia-smi, which takes longer to start than a GPU stage now takes to
# finish; it is meaningless on a Mac.
nvidia-ml-py ; sys_platform != "darwin"
psutil

# ── TTS: torch ─────────────────────────────────────────────────────────────
# Windows/Linux: the +cu124 local-version tag is what makes it a GPU build,
# and pinning it EXACTLY is load-bearing. Left unpinned, pip sees candidates
# on both PyPI and the torch index and backtracks through multi-GB wheels for
# a very long time before settling. One candidate means one download.
# 2.6.0 is the only cu124 build for cp313/win_amd64; bump both together.
#
# torchaudio must match torch and come from the SAME index: transformers 5.x
# imports it to load VITS, and installing f5-tts-th otherwise drags in
# whatever torchaudio PyPI has latest, built against a much newer torch. Its
# C++ extension then fails to load ("[WinError 127] The specified procedure
# could not be found") and takes the working MMS path down with it.
--extra-index-url https://download.pytorch.org/whl/cu124
torch==2.6.0+cu124      ; sys_platform != "darwin"
torchaudio==2.6.0+cu124 ; sys_platform != "darwin"

# macOS: plain PyPI wheels. Apple Silicon gets Metal (MPS) support built in;
# there is no CUDA to ask for. Keep torch and torchaudio on the same minor.
torch      ; sys_platform == "darwin"
torchaudio ; sys_platform == "darwin"

transformers

# 16 kHz (MMS) -> 24 kHz (voice bridge) resampling
scipy
numpy

#   Windows/Linux : install ffmpeg yourself
#   macOS         : brew install ffmpeg
# Enable with TTS_ENGINE_TH=f5 once installed:
