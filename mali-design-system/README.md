# @notuning/mali-ds

MALI design system (no tuning). Tokens + React primitives for MALI Prescreening — kiosk, nurse and admin.

```bash
npm i && npm run build      # dist/index.js, index.d.ts, styles.css, fonts/
```

Usage: import `@notuning/mali-ds/styles.css` once, wrap the app in `<div className="mali-root">`, then use the components. Tokens live in `src/tokens/`. Design-sync config in `.design-sync/` (Claude Design project "MALI Design System").
