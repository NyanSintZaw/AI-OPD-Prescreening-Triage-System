One primary per view. `primary` is ink-900 on paper; `secondary` is a hairline; `ghost` for tertiary actions; `danger` only for destructive or escalation actions. `size="kiosk"` (64px, 22px text) is mandatory for any patient-facing control. Press feedback is scale(.97), 140ms — never add colour flashes. `loading` swaps in a Spinner and disables.
